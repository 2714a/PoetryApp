# 诗词录（PoetryApp）

一款纯离线的中国古诗词与传统文化学习应用，用 Jetpack Compose 构建，油画风格 UI。

## 功能

- **诗词库**：诗经、楚辞、曹操、唐诗、宋词、元曲、纳兰性德等，共 900+ 篇（繁简兼容搜索）
- **诗词解析**：译文、注释、创作背景（带缓存）
- **王朝演变时间轴**：从夏朝到当代，25 个朝代的起止年份、建立者、都城、演变简述
- **百科知识**：本草纲目（12 味药材）、动物（哺乳/鸟类/爬行/昆虫/鱼类）、花卉、水果、四大名著、四大发明
- **作物来历**：辣椒、番茄、土豆、红薯的来历与小故事
- **传统文化**：歇后语、谜语、脑筋急转弯
- **油画风格 UI**：暖色调、卡片化设计
- **完全离线**：所有数据打包在 assets，无需网络
- **首次启动介绍页**：合规声明需勾选同意

## 构建环境

- Android Studio Hedgehog 或更新版本
- JDK 17
- Android SDK 35（minSdk 26）
- Gradle 8.7 / AGP 8.5.2 / Kotlin 2.0.20

## 编译

```bash
./gradlew assembleDebug
```

生成 APK 在 `app/build/outputs/apk/debug/app-debug.apk`。
